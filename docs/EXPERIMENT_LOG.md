# Experiment log

## EXP-001 - Participant-disjoint 1D CNN baseline

**Date:** 2026-11-03  
**Status:** Completed as a validation-only baseline; not suitable for deployment.

### Data

- Processed windows: 3,154 (1,873 swallow; 1,281 non-swallow).
- Input shape: 4 channels x 3,200 samples.
- Sampling rate: 16 kHz.
- Window duration: 200 ms.
- Split: participant-disjoint StratifiedGroupKFold.
- Train: 2,248 windows from 121 participants.
- Validation: 449 windows from 28 participants.
- Test: 457 windows from 26 participants.
- Participant overlap: zero.

### Model and training

- Three Conv1D blocks: 16 / 32 / 64 channels.
- Kernel sizes: 31 / 15 / 9.
- Batch normalization, ReLU, max pooling, adaptive average pooling.
- Adam optimizer, learning rate 0.001.
- BCEWithLogitsLoss with positive-class weight 0.6839.
- Batch size 64, maximum 50 epochs, early-stopping patience 10.
- Checkpoint selection: validation F1 at threshold 0.5.
- Hardware: NVIDIA GeForce RTX 3050 6GB Laptop GPU.
- Best checkpoint: epoch 1.

### Validation result

| Metric | Result |
|---|---:|
| Accuracy | 57.68% |
| Precision | 59.27% |
| Recall | 91.35% |
| Specificity | 8.74% |
| F1 | 71.89% |
| ROC AUC | 0.5263 |

Confusion matrix, rows=true and columns=predicted, class order non-swallow / swallow:

| | Predicted non-swallow | Predicted swallow |
|---|---:|---:|
| True non-swallow | 16 | 167 |
| True swallow | 23 | 243 |

The model has poor discrimination. Its validation F1 is below the all-positive baseline for this class distribution, and its AUC is close to chance. Do not describe this as a successful detector.

### Validation-only diagnostics

- CNN train AUC: 0.5618.
- CNN validation AUC: 0.5263.
- Logistic regression on handcrafted features: validation AUC 0.5527.
- Random forest on handcrafted features: validation AUC 0.5817.
- The model's validation probabilities for the two classes are very close.
- Raw annotated-event RMS medians were lower than safe-background medians on all four channels. This is a statistical difference, not evidence of clinically useful classification.

### Test-set policy

The held-out test split was not used for training, threshold selection, or these diagnostics. It remains untouched. Do not run the final test evaluation until preprocessing and model selection decisions are frozen.

### Interpretation and next work

This result does not reproduce the historical 99.41% accuracy / 99.50% F1 / 0.9999 AUC claim. Possible causes include differences in the historical window extraction, label interpretation, normalization, negative-window sampling, or an optimistic historical evaluation procedure. These are hypotheses, not established explanations.

Next:
1. Verify annotation timing and crop alignment against raw waveforms.
2. Reconcile the 1,873 extracted positive windows with the historical 1,827.
3. Compare a separately versioned amplitude-preserving normalization experiment.
4. Continue using participant-disjoint validation only for model selection.
5. Evaluate the held-out test once only after the protocol is frozen.

The current checkpoint is an experimental baseline only. The project remains a swallow-event research prototype, not aspiration detection or a clinical system.

## EXP-003 - Label-overlap audit and corrected negative sampling

**Date:** 2026-11-03  
**Status:** Completed as a separately versioned experiment.

- Audit of the original saved 3,154-window dataset found 496 of 1,281 negative windows (38.7%) overlap positive annotated windows in the same recording.
- The original 50 ms guard did not account for the 100 ms half-window extent on both sides of the event centre.

- The original dataset under data/processed was not overwritten.

## EXP-004 - Balanced corrected dataset and model comparison

**Date:** 2026-11-03  
**Status:** Exploratory; held-out test evaluated once.

- Created a separate 100 ms guard dataset with 1,873 genuine negative windows sampled from safe background candidates and 1,873 positive annotated windows. No synthetic signals or duplicated windows were added.
- Participant-disjoint split: train 2,676 windows / 127 participants; validation 527 / 25; test 543 / 23. No participant overlap.
- Compared 256-point and 512-point log-STFT spectrogram CNNs, a time-domain 1D CNN, Random Forest and RBF SVM. Channel scales were fit on training participants only.
- Validation-selected ensemble weights: 0.4 spectrogram CNN (256-point), 0.2 spectrogram CNN (512-point), 0.2 RBF SVM, 0.1 Random Forest, 0.1 time-domain 1D CNN. Threshold 0.5.
- Validation metrics: accuracy 71.16%, balanced accuracy 71.09%, precision 74.22%, recall 63.98%, specificity 78.20%, F1 68.72%, AUC 0.7507.
- One-time held-out test metrics: accuracy 59.67%, balanced accuracy 59.72%, precision 61.45%, recall 57.71%, specificity 61.74%, F1 59.52%, AUC 0.6506. Confusion matrix [[163,101],[118,161]] (true rows and predicted columns; non-swallow then swallow).
- The test result is below the 68.67% majority-class accuracy for that test split. The large validation/test gap suggests weak generalization / participant variability. Do not present validation performance as final expected performance.
- After this evaluation, the test set is considered spent and must not be reused for model or threshold tuning. A fresh independent cohort or a pre-registered nested group-CV protocol is required for a new unbiased final estimate.

## EXP-006 - Signal-only ceiling (no window-position features)

**Date:** 2026-11-03  
**Status:** Completed; defines the honest signal-only ceiling.  
**Script:** `scripts/experiment_signal_only_baseline.py`  
**Report:** `artifacts/reports/signal_only_baseline_experiment.json`

### Question

The earlier ceiling note claimed signal-only models top out around 0.65-0.75 AUC, but that number came from several small one-off scripts. This experiment rebuilds a single, richer signal-only feature set to test whether that ceiling actually holds, or whether it was an artefact of weak features.

### Method

- Only the 200 ms four-channel window is used. `start_ms`, recording length, per-recording aggregates and every other metadata field are excluded by construction; the builder takes a window array and nothing else.
- Channel scaling uses the 99.5th percentile of absolute amplitude computed on training participants only.
- Features (3,405 total): 40 log-spaced mel bands per channel at 256-point STFT with 64-sample hop, pooled into 10 segments plus deltas, per-band mean and standard deviation over time, and 11 handcrafted per-channel descriptors (log RMS, crest factor, spectral flatness, centroid, bandwidth, 50%/85% roll-off, zero-crossing rate, envelope coefficient of variation, envelope peak-to-mean, spectral flux) plus a microphone-to-accelerometer energy ratio.
- Four models: Extra Trees, Random Forest, RBF SVM, logistic regression. Four pre-specified blend weightings were compared on validation AUC only.

### Result

| Model | Validation AUC |
|---|---:|
| Extra Trees | 0.7242 |
| Random Forest | 0.7219 |
| RBF SVM | 0.6696 |
| Logistic regression | 0.6567 |
| Best blend (`tree_heavy`) | 0.7273 |

Blend at threshold 0.495:

| Split | Accuracy | Balanced accuracy | F1 | AUC |
|---|---:|---:|---:|---:|
| Validation (model selection) | 67.74% | 67.73% | 67.18% | 0.7273 |
| Test (spent, descriptive only) | 61.88% | 62.19% | 57.84% | 0.6643 |

### Interpretation

The signal-only ceiling is real. Careful feature engineering moved validation AUC from roughly 0.65 to 0.727, but every model family converges near the same place and the test split lands near 0.66. There is no feature set, architecture or blend inside this dataset that reaches 98-99%. The gap from 0.73 to 0.99 is a data problem, not a modelling problem: 200 ms four-channel windows centred on annotated swallow events do not separate reliably from guarded background windows across unseen participants.

The test numbers are printed for completeness only. That split was spent in EXP-004 and no selection step in this experiment reads it.

## EXP-007 - Position-augmented research ensemble (NOT a detector)

**Date:** 2026-11-03  
**Status:** Research artefact; must not be presented as detection accuracy.  
**Script:** `scripts/experiment_position_augmented.py`  
**Report:** `artifacts/reports/position_augmented_experiment.json`  
**Checkpoint:** `artifacts/checkpoints/position_augmented_ensemble.joblib`

### What it does

Adds 16 window-position features derived from recording metadata (`start_ms`, recording length, position ratio, per-recording start-time mean/std/min/max/count, and their normalized variants) to the same four-channel windows, then stacks Random Forest, Extra Trees, Histogram Gradient Boosting and logistic regression behind a logistic meta-learner. The decision threshold is selected on validation only.

### Result

| Split | Accuracy | Balanced accuracy | Precision | Recall | Specificity | F1 | AUC |
|---|---:|---:|---:|---:|---:|---:|---:|
| Validation | 95.45% | 95.43% | 96.47% | 94.25% | 96.62% | 95.35% | 0.9891 |
| Test (spent) | 92.45% | 92.51% | 94.74% | 90.32% | 94.70% | 92.48% | 0.9846 |

### Why this is not the accuracy the project needs

The gain comes almost entirely from `start_ms`. Swallow events cluster early in these short clips while non-swallow windows are sampled uniformly across each recording, so window position leaks the label. A deployed detector receives one window at a time and cannot use this cue, and any recording where events are not front-loaded would break it.

Evidence for the artefact:

- Signal-only models on the same windows reach 0.73 validation AUC (EXP-006); adding position alone lifts it to 0.99.
- Roughly 92-95% is reachable from position features even with a deliberately leaky random window split, which is the signature of a label leak rather than a physiological discriminant.

Consequences:

- The checkpoint is written with `research_only: true` and `clinical_validity: false`. It is not connected to the API, dashboard or inference helper.
- These numbers must never be quoted as swallow-detection or aspiration-detection accuracy.
- Closing the gap to 98-99% honestly requires new data: more participants, denser annotation inside recordings, and an independent aspiration outcome label that this dataset does not contain.
